# Лабораторная работа № 2: Списки

**Вариант:** 4 (Двусвязный циклический список)

**Задание:** № 8 (Объединение упорядоченных списков без дубликатов)

**Дисциплина:** Алгоритмы и структуры данных (АиСД)

**Семестр:** 3

## 📋 Описание задания

Необходимо реализовать шаблонный класс связного списка `LinkedList` в соответствии с вариантом, а также решить одну из практических задач.

### Тип списка (Вариант 4):
**Двусвязный циклический список**. Каждый узел (Node) содержит указатель на следующий (`next`) и предыдущий (`prev`) элемент. Последний элемент списка ссылается на первый, а первый — на последний (цикличность).

### Общие требования к классу:
- Конструктор по умолчанию.
- Конструктор копирования (глубокое копирование).
- Конструктор со случайными значениями (с использованием seed).
- Деструктор.
- Операция присваивания.
- Добавление элемента в конец (`push_tail`) и в начало (`push_head`).
- Удаление элемента с конца (`pop_tail`) и с начала (`pop_head`).
- Операция доступа по индексу (чтение/запись) с учетом цикличности.
- Перегрузка оператора вывода в поток (`<<`).

### Основная задача (Задание 8):
Создать два списка упорядоченных чисел. Объединить эти два списка так, чтобы сохранился отсортированный вид (итоговый список **не должен содержать дубликатов**).

## 🛠 Реализация

### Класс `LinkedList<T>` и структура `Node<T>`
- Список управляет памятью вручную (выделение через `new`, удаление через `delete`).
- Реализовано **Правило трех** (деструктор, конструктор копирования, оператор присваивания), чтобы избежать утечек памяти и двойного удаления.
- Для доступа по индексу в циклическом списке используется операция взятия по модулю (`index % size_`), что позволяет корректно обращаться к элементам, даже если индекс превышает размер списка.
- При некорректных операциях (выход за границы, пустой список) выбрасываются исключения `std::out_of_range` и `std::underflow_error`.

### Алгоритм решения Задачи 8 (Merge Sort approach)
1. Мы проходим по обоим спискам одновременно, используя два индекса (`i` и `j`).
2. Сравниваем текущие элементы списков и добавляем в результирующий список **меньший** из них.
3. **Удаление дубликатов:** перед добавлением элемента в результат мы проверяем, не равен ли он последнему добавленному элементу. Если равен — пропускаем.
4. Если один список закончился раньше, оставшиеся элементы второго списка добавляются в результат (с той же проверкой на дубликаты).

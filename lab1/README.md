## 📋 Описание задания

Необходимо реализовать шаблонный класс векторов произвольной размерности, обеспечивающий работу с типами `int`, `float`, `double`, `std::complex<float>` и `std::complex<double>`.

### Основные требования к классу:
- Конструктор с параметрами (размерность и значение для заполнения).
- Конструктор со случайными значениями (размерность, нижняя и верхняя границы).
- Оператор `[]` для чтения/записи элемента по индексу.
- Операторы сложения и вычитания векторов.
- Оператор умножения (скалярное произведение). Для комплексных чисел реализована корректная специализация с использованием сопряжения (`std::conj`).
- Оператор умножения вектора на скаляр (с обеспечением коммутативности).
- Оператор деления вектора на скаляр.

### Основная задача (Задача № 4):
Для заданного вектора `a` найти любой перпендикулярный ему единичный вектор.

## 🛠 Реализация

### Класс `Vector<T>`
- Данные хранятся в динамическом массиве (`T* data_`).
- Реализовано **Правило трех** (Rule of Three): деструктор, конструктор копирования и оператор присваивания для предотвращения утечек памяти.
- Для строгого сравнения вещественных чисел используется статическая константа `EPSILON = 1e-9`.
- При некорректных операциях (выход за границы, несовпадение размеров) выбрасываются исключения `std::out_of_range` и `std::invalid_argument`.

### Алгоритм решения Задачи № 4
1. Берется исходный вектор `a`. Если его размерность меньше 2, выбрасывается исключение.
2. Создается новый вектор `b`, заполненный нулями.
3. Первые две координаты `a` переставляются местами со сменой знака у одной из них: `b[0] = -a[1]`, `b[1] = a[0]`. Это гарантирует ортогональность (скалярное произведение `a * b` равно нулю).
4. Вычисляется норма (длина) полученного вектора.
5. Вектор нормализуется (делится на свою норму), чтобы стать единичным.
